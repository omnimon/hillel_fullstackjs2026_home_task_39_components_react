# React Homework 39 — Stateful vs Stateless Components

A small React + TypeScript project for the Hillel FullStack JavaScript course.

The project demonstrates the difference between stateful and stateless React components.

## Features

- `StatefulCounter` uses `useState` and manages its own state.
- `StatelessMessage` receives data through props and only renders it.
- Functional React components.
- TypeScript.
- Vite.

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd hillel_fullstackjs2026_home_task_39_components_react
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build

Create a production build:

```bash
npm run build
```
